What is still needed (fill these in by hand)

meta title        :

How to capture them
-------------------
From any machine with normal internet access:

  curl -s https://femfast.io/ \
    | grep -Ei '<title>|name="description"|property="og:image"'

Or: open https://femfast.io/, View Source, and read the three tags from <head>.

Where these values are consumed
-------------------------------
src/site.config.mjs  ->  title / description / ogImage
Those feed the <title>, <meta name="description">, and og:/twitter: tags that
/scripts/build.mjs writes into every route. Until the real values are supplied,
the build uses the fallback copy defined in that config file (see the
`tildaMetaCaptured: false` flag there).

Guard required by the brief
---------------------------
If the recovered Tilda title or description contains the words "diet" or
"weight loss", do NOT copy it across — a replacement must be proposed and
approved first.
